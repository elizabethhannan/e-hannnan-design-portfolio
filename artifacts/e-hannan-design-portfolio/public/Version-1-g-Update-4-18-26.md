WHY A SERIES CONTINUES AFTER ITS EPILOGUE
Version 1.f declared the series complete. Version 1.g proves a practical truth about documentation systems: the endpoint is a declaration of intent, not a hard stop. A series continues as long as there is work to document.
The correct response when a "closed" series receives a new entry is not to restart from a new major version — it is to extend using the next available letter and update the index (1.f) to reflect the addition.

CONTINUATION RULES
When to continue the current major version (1.x)
Continue with the next letter when:
* The session is still ongoing (same date, same site, same project)
* The new document covers additional prompts from the same April 18 session
* No new styling changes were made — only documentation prompts
When to start a new major version (2.x)
Start a new major version when:
* A new coding session begins on a different date
* Significant new styling changes are made that require new code documentation
* A different site or project is being documented
